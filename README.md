# どうぶつベースボール

デフォルメされた動物たちが本物の野球ルールで戦う 3D 野球ゲーム。
**外部ライブラリなし・単一 HTML ファイル**で動きます（WebGL 1.0 を自前で叩いています）。

- ひとりでプレイ（対 CPU）／ふたりで対戦（キーボード 1 台を交代で使用）
- イニング数は 3・6・9 回から選択（初期値 6 回）
- 球場は 5 種類：みどりが丘スタジアム／国道17号線のまんなか／スーパーおおぞら店内／河川敷グラウンド／月面クレーター球場
- ルールは厳密：盗塁、ボーク、暴投、振り逃げ、インフィールドフライ、送りバント、サヨナラの得点上限まで

---

## ビルド

`src/` の各ファイルを連結して `animal-baseball.html` を生成するだけです
（連結するときにコメントだけの行と字下げを落とします）。

```bash
sh build.sh
```

生成された `animal-baseball.html` をブラウザで開けばそのまま動きます
（サーバー不要。`file://` で開けます）。

構文チェックだけしたい場合：

```bash
cat src/*.js > /tmp/all.js && node --check /tmp/all.js
```

## ファイル構成

| パス | 役割 |
|---|---|
| `build.sh` | `src/` を連結して単一 HTML を出力するビルドスクリプト |
| `animal-baseball.html` | **ビルド成果物**。これ 1 つで動く。公開しているのもこれ |
| `src/00-shell.html` | HTML の外枠、CSS、HUD・メニューのマークアップ |
| `src/10-core.js` | 行列演算、プリミティブ生成、WebGL レンダラ、効果音 |
| `src/20-world.js` | フィールドのライン、5 球場の定義と背景、車・買い物客 |
| `src/30-actors.js` | 動物キャラクターのモデリングと描画、チームデータ |
| `src/40-game.js` | 野球のルール、打球の物理、守備判定、走塁 |
| `src/50-main.js` | 画面遷移、入力、カメラ、毎フレームの更新と描画 |
| `patches/` | 開発中に使った一度きりの差分適用スクリプト（**ビルドには不要**） |
| `tools/` | 開発ツール。`tools/sim.js` は CPU 同士の自動対戦をヘッドレスで回す（**ビルドには不要**） |

`patches/` は開発履歴として残してあるだけで、`build.sh` からは参照されません。
不要であればフォルダごと削除して構いません。

## 設計メモ

**レンダラ** — 球・箱・円柱・円錐・丸角ボックス（スーパー楕円体）・押し出し多角形といった
プリミティブを 1 本の頂点バッファに詰め、1 パーツ 1 ドローコールで描いています。
セルシェーディング＋接地影。キャラクターは輪郭線パス（インバーテッドハル）付きで、
線画調に見えるようにしています。

**判定と表示の一致** — 打球は物理シミュレーションし、**各野手が実際にいつ・どこで
グラブに触れられるか**を計算してから、送球と走者の到達時刻を競走させて結果を決めます。
アニメーションはその計算結果（プレースクリプト）をそのまま再生するので、
実況・打球の位置・野手の動きが食い違いません。

**成績の較正** — CPU 同士の自動対戦を回して実際の野球の統計に合わせてあります
（打率 .24 前後、1 試合あたり安打 8、本塁打 1.1、三振 8〜9、四球 4 程度）。

## 操作

| | 打席 | 守備（投球） |
|---|---|---|
| ねらう | 矢印キー / マウス | 矢印キー / マウス |
| 決定 | スペース（スイング） | スペース（投球） |
| その他 | Shift＋スペースでバント | 1〜5 で球種 |

`Esc` または画面右上の「ポーズ」で中断できます。
